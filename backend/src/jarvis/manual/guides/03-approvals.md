# Approvals and autonomy
Every change is an **action** with a tier:

- **Automatable (T1):** low-risk changes that only affect you (create a task, add a calendar block, save an email draft,
  play music, turn on a light). You can create a rule in Actions → Policies so these are approved for you, with a daily
  limit. Auto-approved actions can be undone for 5 minutes.
- **Always ask (T2):** anything that reaches other people (sending email, posting to Slack channels), deletes, locks,
  alarms and garage doors, sandbox internet access, installing skills. A rule can never approve these.

Rules only apply to the source you chose: your own commands by default. Turn on "missions" or "channels" for a rule
only if you want background missions or Telegram messages to use it.

Pause actions (top bar) holds everything instantly; resuming never replays held approvals.
