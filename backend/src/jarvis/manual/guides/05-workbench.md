# Workbench, sandbox and skills
The sandbox is a disposable Linux computer inside Docker on your machine. JARVIS can run code, use a real browser and
operate a virtual desktop there. It can't see your files or accounts.

- **Internet:** off by default. When a task needs it, JARVIS asks to open access to specific sites for a limited time.
- **Files:** copying a result to your workspace folder is an approval card with a preview.
- **Watch it work:** the Workbench shows every command and the latest screen. Stop or reset it any time.
- **Setup:** Docker Desktop → Settings → Resources → WSL integration (enable for your distro), then Workbench → Build.

**Skills** are saved how-tos ("how I format my weekly report"). Install one from a folder with a SKILL.md, or ask
JARVIS to draft one; you review the exact text before it's installed.
